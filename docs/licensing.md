# Licensing and ignore policy

## Recommended setup

- License original solution code under MIT for straightforward reuse, provided the team is comfortable allowing reuse and redistribution with attribution.
- State the license scope clearly: it applies only to original project code/docs. Competition data remains under the enrollment terms and is not licensed by this repository.
- Preserve upstream copyright and license notices for any copied or modified starter files. Track dependencies/models and their licenses in `THIRD_PARTY_NOTICES.md`.
- Keep the data bundle, private labels, generated full-match submissions, and local paths out of Git. Review `git status` and the staged diff before every public push.

The MIT license is permissive. If the team does not want others reusing its code, do not add a permissive license; however, organizers still need public access to inspect and run the submission. Agree on the team’s preference before publishing. Replace the copyright placeholder in `LICENSE` with the final team name or copyright holder.
